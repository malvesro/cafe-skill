# Template de Pedido — ☕ Café

Use este template para registrar pedidos customizados antes de calcular
ingredientes e tempo de preparo.

---

## Pedido

```
Método de preparo : [ ] Coado  [ ] Prensa Francesa  [ ] Cold Brew  [ ] Espresso
Quantidade        : ___ xícaras
Força             : [ ] Fraco  [ ] Médio  [ ] Forte
Temperatura serve : [ ] Quente  [ ] Gelado
Observações       : ___________________________________________________
```

---

## Cálculo Automático (Coado)

| Xícaras | Café (g) | Água (ml) | Temperatura | Tempo de extração |
|---------|----------|-----------|-------------|-------------------|
| 1       | 10 g     | 150 ml    | 93 °C       | 3–4 min           |
| 2       | 20 g     | 300 ml    | 93 °C       | 3–4 min           |
